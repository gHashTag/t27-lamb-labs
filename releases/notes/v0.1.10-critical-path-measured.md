v0.1.10-critical-path-measured: the KV mux, not the accumulator

Co-design iteration 7 measures which path limits the design to 65-73 MHz, by deleting each
candidate from an otherwise identical design.

  baseline              71.86 MHz
  no accumulator loop    59.77 MHz  <- removing it made it SLOWER
  no score multiply     74.13 MHz  <- only +3.2%

So the limiter is the KV-cache read mux: a 32-to-1 dynamic-index mux per channel, in series with
the sign select, the add and the accumulator mux. Iteration 6's attribution to the accumulator was
wrong and is corrected in the record.

Next: pipeline the KV read (fetch slot N+1 while accumulating slot N), 18 -> 19 cycles/token.
The achievable Fmax is a TARGET until measured.
