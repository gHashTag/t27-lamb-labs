=== WRAP-ALIASING ANALYSIS: R4/T4 run 1, 2026-11-23 (0.5 s interval) ===

The 20-bit counter wraps at 2^20 = 1048576 COUNTS. At the established rate
(~397.6 MHz / 256 = 1.553e6 counts/s) one wrap takes 0.675 s - inside the run-1
window (~0.68 s at 0.5 s interval + read overhead). measure_clock.py computes plain
deltas, so a window that crossed the wrap once reports a tiny/near-zero delta.
Yesterday's windows were 335 ms (< wrap); today's run-1 windows were not.

Reconciliation: MHz = (delta + k*2^20)/dt * 256 / 1e6 for k = wraps crossed.
