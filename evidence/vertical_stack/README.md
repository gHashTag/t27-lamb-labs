## Two strictly separate stories

| Branch | Subject | Where the evidence lives |
|---|---|---|
| **A — GPU kernel path** | numeric SSOT → executable spec → CPU oracle/conformance → PTX emission → offline assembly → host integration → GPU correctness | this directory + `specs/` + `scripts/gf16_dot4_host/` + `artifacts/gf16-dot4-ptx/` |
| **B — hardware path** | spec → RTL → simulation → FPGA → silicon | this directory (`rtl_fpga_inventory.md`) + `specs/fpga/` + `bitstream/` + `evidence/` |

The branches share only the numeric SSOT (`specs/numeric/gf16.t27`) and the machine-readable
vectors. Names that match across branches (`gf16_dot4`) denote **different designs**; never move a
claim between them. Performance/power evidence is a **third, separate** track and is still
unauthorized.

## Reproduce the GPU correctness verdict

```sh
# 1) native .t27 oracle + batch self-tests + merged GPU verdict
t27c test-report scripts/gf16_dot4_host/gf16_gpu_batch.t27
#    -> exit 0, tests 6, pass 6, FAIL 0

# 2) statistics emitted by the .t27 module
t27c gen-text scripts/gf16_dot4_host/gf16_gpu_batch.t27 \
    --fn batch_stats_dump --buf 256 -o batch_stats.txt
#    -> nan_grps=38 / fmmatch=0 / nanviol=0

# 3) the GPU run itself (remote CUDA host, driver API only)
#    scripts/gf16_dot4_host/gpu_smoke.sh  -> hash gate, GPU gate, build, launch,
#    synchronize, D2H, completeness; ordinal 0 (the CUDA-visible device)
```

The CUDA runner is the only non-`.t27` bridge in the chain: it exists solely to call the CUDA
driver API (`cuInit` … `cuCtxDestroy`) and to move bytes. All semantics, oracle, comparator and
verdict logic is native `.t27`.

## What is NOT claimed here

* No performance, throughput, occupancy, latency, power or energy numbers for this kernel.
* No training of any kind (`TRAINING_APPROVED=false`).
* No simulation output for the FPGA GF16 branch, no attention bitstream, no tapeout artifacts.
* The 288-group GPU batch is a regression corpus, not an exhaustive proof over all input pairs.
* Historical reports are cited as MEASURED **at their timestamp**, never as fresh runs.
