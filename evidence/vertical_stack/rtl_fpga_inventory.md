# RTL → FPGA Vertical Inventory (M5)

**Scope.** Inventory of the hardware evidence chain **spec → RTL → simulation → FPGA** as it
actually exists in this repository (worktree `dsh-5344b40f-4225`, HEAD `71745d5`).

**Method.** Read-only inspection: `glob`, `grep`, `read`, and `shasum -a 256`. No Vivado/iverilog
runs, no synthesis/place-and-route re-runs, no git write commands, no network/GPU. Exactly one
file was created (this one). All hashes below are SHA-256 of the on-disk bytes in this worktree.

**Label legend.**

| Label | Meaning as used here |
|---|---|
| `MEASURED` | A value was read out of a tool or a board and is recorded in the cited artifact. Old reports are **historical MEASURED at their timestamp** — the label does not mean "still valid today". |
| `ESTIMATED` | Modelled / derived / arithmetic from measured inputs; never a direct measurement. |
| `TARGET` | A goal stated in docs, not an observation. |
| `SUSPECT` | Recorded as a measurement but contradicted, withdrawn, or explained away by later evidence. |
| `GAP` | Required link or artifact is absent from this repository. |

**Dates.** "date" is the timestamp *inside* the artifact. File mtimes in this worktree are all
`2026-11-23 11:53` (checkout copy time) and carry no evidentiary meaning, so they are not used.

## 0. Branch separation map (strict)

The repository contains **three disjoint hardware stories** that share vocabulary but share no
artifact. Claims must never be moved between them.

| # | Branch | Owning paths | What it is | Status |
|---|---|---|---|---|
| **A** | **Corrected-attention branch** | `evidence/attention/`, `evidence/attention_fix/`, `evidence/attention_joint/`, `evidence/attention_seq/`, `evidence/attention_token/`, `evidence/utilization/`, `evidence/critical_path/`, `evidence/fmax_noise/`, `evidence/clock/`, `evidence/clock_probe/`, `evidence/xadc/`, `evidence/codesign/` | Hand-written attention RTL + its synthesis/timing/telemetry harnesses. | Resource + bit-exactness numbers **MEASURED**; throughput **not measured**; no spec file. |
| **B** | **GF16 / ternary-MAC shipped-bitstream branch** | `specs/fpga/gf16_accel.*`, `bitstream/ternary_mac_demo_top_200t.bit`, `docs/`, `evidence/reports/`, `evidence/variance_summary*.json`, `evidence/artifact_run_*.json`, `evidence/run_*.log` | The one real `.bit` and the FPGA GF16 spec/RTL. | Bitstream **MEASURED real**; the MAC datapath inside it **pruned away**; throughput **WITHDRAWN**. |
| **C** | **GPU GF16 dot4 / PTX branch** | `specs/igla/coder/gf16_dot4_ptx.t27`, `specs/igla/coder/ptx_emit.t27`, `specs/numeric/gf16.t27` | CUDA/PTX kernel + GF16 numeric SSOT. | Present on disk, GPU-side, **not** part of the FPGA chain. |

**Non-conflation rules enforced in this document:**

* `specs/fpga/gf16_accel.t27` / `.v` (FPGA GF16 hardware) and `specs/igla/coder/gf16_dot4_ptx.t27`
  (GPU GF16 dot4 PTX) are **different designs**. `specs/numeric/gf16.t27` is the shared numeric
  SSOT only (`specs/numeric/gf16.t27:2-8`).
* The shipped `.bit` was **not** produced from `specs/fpga/*.t27` or `specs/fpga/*.v`
  (`evidence/utilization/shipped_bitstream_stat.txt:7-23`).
* Branch A and Branch B share **no** RTL file. Where one branch's artifact measures the other
  branch's design, it is listed in §6 (Cross-branch links) and flagged, never blended.
* `evidence/vertical_stack/` (this directory) also holds a **GPU-GF16 host-ABI lane**
  (`HOST_ABI.md`, `READINESS_MATRIX.md`, `PROVENANCE.md`, `vectors/`, `reports/`) which is
  **out of scope** for the RTL→FPGA chain and is not inventoried here.
